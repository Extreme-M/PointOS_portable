# Welcome to the PointOS_portable Project
## Goals
PointOS_portable is an Operating system designed to be booted off an pendrive .
PointOS_portable is designed to be used as a Real time OS (RTOS) to Test the hardware,
Check Hardware issues, and Allow users to access and have absolute control over their hardware.
## Kernel
For now the OS is designed to be ran in Qemu or any Virtualisation due to lack of Proper Graphics driver, GPT and Proper IDTs and Interrupts.
The kernel is designed for X86 and AMD64 architecture.
## Future
To be honest. The project will need a lot of work. The main focus for now are to implement Syscalls, Runtime and Proper Bash implementation.
